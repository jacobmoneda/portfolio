Overview

I developed a personal retrieval-augmented generation system spanning four university courses and approximately 1,000 lecture slides. The focus was reliable retrieval and traceable source citations.

My contribution

  • Designed metadata linking material to courses, lectures and slide numbers.
  • Developed document chunking and embedding approaches for PowerPoint content.
  • Investigated how document structure affects retrieval.
  • Worked on source traceability and debugging weak retrieval results.

Approach

The work examined how course material is represented for retrieval. Document chunking and embedding approaches were developed alongside metadata that identifies the course, lecture and slide associated with material.

A central concern was tracing retrieved information back to its source and investigating weak retrieval results. A future walkthrough will show an actual query, its response and the relevant source material.

Visual evidence

Actual interface captures and a query with its source citation will be added when available. The repository does not yet contain these assets.

Status and limitations

The language, framework, embedding model, storage system and evaluation method are not yet specified on this project page. Corpus size establishes scope; it does not establish answer accuracy or citation correctness.
