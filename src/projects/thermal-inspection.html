Overview

This ongoing research work involves robotic inspection capabilities that combine automated arm movement, thermal image analysis and robot localization.

My contribution

  • Designed and implemented automated robotic arm positioning sequences for repeatable thermal inspections.
  • Developed Python tools to process radiometric imagery and extract temperature statistics.
  • Visualized thermal analysis results through a web-based dashboard.
  • Worked with ROS 2 and LiDAR-based SLAM toward repeatable localization and inspection positioning.
  • Developed C++ software for robotic arm control.

Approach

My documented contributions connect robotic arm positioning with the processing and presentation of thermal measurements. Python supports image processing and temperature statistics, while C++ is used for robotic arm control.

The localization work uses ROS 2 and LiDAR-based SLAM toward repeatable inspection positioning. This remains ongoing work; the complete system architecture and implementation boundaries will be described when confirmed and permitted for publication.

From setup to analysis

The lab setup pairs a robot-mounted arm with a thermal camera. The processing app presents temperature statistics alongside RGB and thermal image views.

Status and limitations

This page does not claim a completed inspection system or verified localization performance. Hardware details, outcomes and the boundary between personal and team contributions require further documentation. The digital twin description is deferred until that part of the work is substantiated.
