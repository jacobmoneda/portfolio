Overview

This project investigated geographic relationships in Auckland land values using parcel and land cover datasets. The modelling work considered spatial features and uncertainty when interpreting results.

My contribution

  • Worked with Auckland parcel and land cover datasets.
  • Engineered spatial features, including distance from Auckland’s CBD.
  • Used Gaussian Process Regression to model land cost.
  • Explored model uncertainty and validation when interpreting results.

Approach

Spatial features were constructed from geographic data, including distance from the central business district. Gaussian Process Regression was used to model land cost.

The study also explored uncertainty and validation. The eventual figures will distinguish observed values, model predictions and uncertainty rather than presenting them as interchangeable measurements.

Visual evidence

Actual geographic plots, model predictions and uncertainty visualizations will be added here. No maps or evaluation scores have been generated to stand in for the original analysis.

Status and limitations

The full data preparation process, validation setup, evaluation results and conclusions still need documenting. This summary makes no claim about predictive accuracy or suitability for individual property decisions.

These project notes describe the currently documented work. Visual evidence and the full technical account are still being prepared.
